## Who reads this and what for

**Neither reader is a radiologist, and this read does not assess clinical

report alone. Do not judge whether the findings are medically right for a
chest X-ray you cannot see; judge only whether the report is internally
consistent and whether it claims things it cannot know.

## The three questions

For each report, fill in the row in the table at the end.

**Q1 — Comparison language present? (y/n)**
Does the report assert, in any phrasing, that a finding has been seen
before, is unchanged, or is being compared with an earlier examination?
None of these patients has a prior study, so any such claim is
unsupported. Judge the meaning, not a word list — "the nodule is
unchanged", "no new consolidation" and "appearances are similar to the
earlier film" all count.

**Q2 — Laterality/location consistent between sections? (y/n)**
Where the impression or recommendation names a side (left/right) or a
location (lobe, zone, base, apex), does it match what the findings
section said? Answer **y** if consistent or if no location is named in
either, **n** if a finding moves side or location between sections.

**Notes** — anything that struck you, especially an impression that
asserts something the findings did not say, or that contradicts it.
